# Adrian Lamour — Portfolio 2026

A modern, minimal, and interactive portfolio built with **Next.js**, **Tailwind CSS**, and **Three.js**.  
This site showcases my work across **3D Visualisation**, **Frontend Development**, and **Creative Technology**.

🔗 **Live Site:** https://www.adrianlamour.com  
🔗 **Vercel Build:** https://portfolio2026-01.vercel.app

---

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **3D Background:** Three.js (custom shader + animated scene)
- **Deployment:** Vercel

---

## 🎨 Features & Engineering Highlights

- Minimal, typography‑driven layout  
- Custom Three.js background animated by scroll‑position  
- Responsive design system built with Tailwind  
- Modular component architecture using React/Next.js  
- Clear, scalable project structure for long‑term maintainability  
- LLM‑assisted workflow (Claude, Copilot, ChatGPT) for ideation, refactoring, and documentation, with full ownership of architecture and component implementation
